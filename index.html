সহায়িকা

কীভাবে ইনকাম করবেন?

EARN পেজে যান এবং উপলব্ধ টাস্ক (যেমন: মেইল সেল, সোশ্যাল মিডিয়া টাস্ক) সম্পন্ন করুন।

কীভাবে ডিপোজিট করবেন?

হেডারের '+' আইকনে ক্লিক করুন। পেমেন্ট মাধ্যম নির্বাচন করুন, টাকা পাঠান এবং TrxID দিয়ে সাবমিট করুন।

কীভাবে উইথড্র করবেন?

হেডারে আপনার ব্যালেন্স-এর উপর ক্লিক করুন। উইথড্র পেজে বিকাশ/নগদ নম্বর ও টাকার পরিমাণ দিয়ে সাবমিট করুন।

যেকোনো প্রয়োজনে মেনু বাটন থেকে সাপোর্টে যোগাযোগ করুন।

How to Deposit

السلام عليكم, আপনাকে স্বাগতম

  1. প্রথমে আপনি যে মাধ্যমে টাকা পাঠাতে চান সেটি নির্বাচন করুন।
  2. এরপর প্রদর্শিত নম্বরে আপনার কাঙ্খিত পরিমাণ টাকা পাঠান।
  3. টাকা পাঠানোর পর, নিচের ফর্মটি পূরণ করুন।
  4. আপনার পাঠানো টাকার মাধ্যম, পরিমাণ, নম্বর এবং Transaction ID (TxID) সঠিকভাবে লিখুন।
  5. সবশেষে "Submit Deposit" বাটনে ক্লিক করুন।

আপনার ডিপোজিট দ্রুত যাচাই করে ব্যালেন্সে যোগ করা হবে।
